### 本轮修正

2. 已进入上游调用后的非法响应和运行时超时改为 `UNKNOWN / warn`，与调用方必须先查单、不得盲目重提的契约一致。

### 当前判断

1. gateway-access 与 payment-core 对提交结果未知的审计语义已一致，不再由接入侧 `FAILED` 错误暗示渠道明确拒绝。
2. 本地模拟只证明分支与展示构建，不证明上游收到请求、真实渠道受理、资金结果、生产网络时序或对账一致性。
