# gateway-access 前端页面与交互说明

## 1. 页面结构

1. 总览看板
2. 接入应用
3. 网关渠道
4. 证书管理
5. 接入权限
6. 调用方审计台账
7. 环境隔离与灰度发布台账

## 2. 交互

1. 刷新总览
2. 每个配置项支持启停
3. 状态标签统一通过 `statusType` 渲染
4. 列表字段顺序保持固定
5. 渠道网关台账支持按关键字、渠道类型和状态筛选，便于运营快速收敛接入排查范围
6. 证书管理表格需展示风险等级、剩余天数和风险提示，便于优先处理临期证书
7. 证书管理页支持按风险等级筛选，运营可直接收口“已过期 / 7天内到期 / 30天内到期 / 正常 / 日期异常”证书
8. 调用方审计台账支持按请求流水号、应用编码和调用结果筛选，失败调用必须展示风险提示
9. 灰度发布台账支持按环境和状态筛选，并展示发布策略、流量占比和发布窗口
