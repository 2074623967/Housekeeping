# 清分清算系统前端页面与交互说明

## 1. 页面范围

### admin-web

1. 清分批次列表页
2. 清分结果列表页
3. 清分规则配置页
4. 费用项配置页
5. 分账明细页
6. 清分任务页

## 2. 页面职责

### 2.0 清分工作台

- 作为清分系统首页，集中展示处理中批次、失败清分、规则生效状态和支付事件链路
- 支持直接跳转批次、清分结果、规则、事件等核心页面
- 首页必须展示最近批次、最近清分结果、最近规则、最近事件四块摘要区

### 2.1 清分批次列表页

- 查看批次日期、订单数、总金额、状态
- 支持发起清分、重跑清分、查看详情
- 支持同页下钻查看批次摘要和关联清分结果

### 2.2 清分结果列表页

- 查看单笔支付对应的拆分结果
- 展示商家、服务者、平台、渠道费用
- 支持同页下钻费用规则快照和分账明细

### 2.3 清分规则配置页

- 维护清分规则版本
- 支持启停和灰度
- 支持查看规则表达式说明和当前版本工作区

### 2.4 费用项配置页

- 维护抽佣、手续费、补贴等费用项
- 支持查看费用模式、承担方和配置工作区

### 2.5 分账明细页

- 展示各收款方分账金额和状态
- 支持查看资金去向说明和按分账类型区分收款对象

### 2.6 清分事件页

- 作为支付成功事件的主入口，支持同页查看事件、清分结果、费用规则和分账明细
- 支持按支付单号回查对应清分结果，验证“支付成功 -> 清分 -> 分账”链路是否完整

## 3. 交互要求

1. 列表页支持筛选和分页
2. 规则配置必须版本化
3. 重跑清分必须二次确认
4. 所有结果必须可追溯到支付单

## 4. 2026-07-28 本轮补充

### 4.1 清分事件页

- 事件页升级为 `事件列表 + 清分结果 + 分账明细` 三段式工作台
- 支持录入完整支付成功事件，并提供日常保洁 / 深度保洁两类业务样例
- 事件消费成功后应自动下钻到对应 `paymentOrderId` 的清分结果
- 清分详情区必须展示费用规则快照和分账明细，支撑财务与产品联调核验

### 4.2 清分结果页

- 清分结果页升级为 `结果列表 + 清分详情下钻` 双段式页面
- 支持按支付单号筛选，并同页展示费用规则快照、分账明细
- 渠道费字段使用红色强调，帮助财务快速识别扣减项

### 4.3 清分批次页

- 清分批次页升级为 `批次列表 + 批次下钻` 双段式页面
- 同页支持查看批次摘要、关联清分结果和重跑操作约束
- 重跑需录入操作人和重跑原因，并在操作前二次确认

### 4.4 清分工作台首页

- 首页升级为运营驾驶舱，分为 `核心待办`、`最近批次与清分结果`、`规则与事件动态` 三块
- 驾驶舱卡片需直出处理中批次、失败清分、启用规则、事件追踪四类核心指标
- 驾驶舱需支持手工刷新，便于运营实时查看清分状态

### 4.5 清分规则页

- 规则页升级为 `规则列表 + 规则工作区` 双段式页面
- 支持新增规则时录入灰度标记，并在同页查看表达式说明
- 启停规则前必须二次确认，降低线上拆分规则误操作风险

### 4.6 费用规则页

- 费用规则页升级为 `规则列表 + 费用规则工作区` 双段式页面
- 支持配置费率、固定金额、承担方，并提供平台服务费 / 渠道费示例
- 固定金额字段在列表中用红色强调，帮助财务快速识别固定扣费项

### 4.7 分账明细页

- 分账明细页升级为 `分账列表 + 资金去向说明` 双段式页面
- 支持统计服务者、商家、平台三类分账数量
- 支持按清分单号、分账类型定位资金流向并查看收款对象说明
