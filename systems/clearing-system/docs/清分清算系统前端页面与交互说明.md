# 清分清算系统前端页面与交互说明

## 1. 页面范围

### admin-web

1. 清分批次列表页
2. 清分结果列表页
3. 清分规则配置页
4. 费用项配置页
5. 分账明细页
6. 清分任务页

## 2. 页面职责

### 2.1 清分批次列表页

- 查看批次日期、订单数、总金额、状态
- 支持发起清分、重跑清分、查看详情

### 2.2 清分结果列表页

- 查看单笔支付对应的拆分结果
- 展示商家、服务者、平台、渠道费用
- 支持同页下钻费用规则快照和分账明细

### 2.3 清分规则配置页

- 维护清分规则版本
- 支持启停和灰度

### 2.4 费用项配置页

- 维护抽佣、手续费、补贴等费用项

### 2.5 分账明细页

- 展示各收款方分账金额和状态

### 2.6 清分事件页

- 作为支付成功事件的主入口，支持同页查看事件、清分结果、费用规则和分账明细
- 支持按支付单号回查对应清分结果，验证“支付成功 -> 清分 -> 分账”链路是否完整

## 3. 交互要求

1. 列表页支持筛选和分页
2. 规则配置必须版本化
3. 重跑清分必须二次确认
4. 所有结果必须可追溯到支付单

## 4. 2026-07-28 本轮补充

### 4.1 清分事件页

- 事件页升级为 `事件列表 + 清分结果 + 分账明细` 三段式工作台
- 支持录入完整支付成功事件，并提供日常保洁 / 深度保洁两类业务样例
- 事件消费成功后应自动下钻到对应 `paymentOrderId` 的清分结果
- 清分详情区必须展示费用规则快照和分账明细，支撑财务与产品联调核验

### 4.2 清分结果页

- 清分结果页升级为 `结果列表 + 清分详情下钻` 双段式页面
- 支持按支付单号筛选，并同页展示费用规则快照、分账明细
- 渠道费字段使用红色强调，帮助财务快速识别扣减项
