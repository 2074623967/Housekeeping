# clearing-system frontend

## 说明

当前目录用于承载 `clearing-system` 的前端实现。

管理端 API client 已具备网络失败、超时和非 JSON 响应的可识别错误码，并对分页列表的 `null`/空 `items` 做统一归一；契约测试 `7/7` 通过，Vite 生产构建通过。这些结果不代表真实清分或资金事实。

第一版目标：

1. admin-web 工作台
2. 清分批次页面
3. 清分结果页面
4. 清分规则页面
5. 费用规则页面
6. 分账明细页面
7. 清分事件页面

1. 已补齐 Vue3 + Vite 工程骨架
2. 已补齐 admin-web 第一版联调页面
3. 后续继续补详情页、任务页、重跑确认和审计视图
