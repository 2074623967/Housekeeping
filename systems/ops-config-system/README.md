# 运营配置系统

运营配置系统负责支付协议、业务线、支付类型、收银台模板、渠道档案、路由规则和系统控制的统一运营台账。

## V1 范围

- 协议模板管理
- 业务线管理
- 支付类型管理
- 收银台模板管理
- 渠道档案管理
- 路由规则管理
- 系统控制管理
- 独立数据库 `housekeeping_ops_config`

V1 先提供后台运营配置基线，并通过配置变更审批与灰度发布降低直接改生效配置的风险；真实渠道验签、风控限额和接入权限编排仍由其他系统负责。

## 已补能力

- 有效配置快照查询
- 有效配置快照导出
- 配置变更申请、审批、灰度窗口和发布留痕
- 配置快照版本号和下游刷新事件
