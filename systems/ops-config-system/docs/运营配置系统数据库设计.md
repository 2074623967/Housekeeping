# 运营配置系统数据库设计

## 数据库

独立数据库：`housekeeping_ops_config`。

## 表设计

| 表名 | 说明 |
| --- | --- |
| `t_ops_agreement_template` | 协议模板 |
| `t_ops_business_line` | 业务线 |
| `t_ops_payment_type` | 支付类型 |
| `t_ops_cashier_template` | 收银台模板 |
| `t_ops_channel_profile` | 渠道档案 |
| `t_ops_routing_rule` | 路由规则 |
| `t_ops_system_control` | 系统控制 |
| `t_ops_config_change` | 配置变更审批与灰度发布 |

所有表统一包含 `status`、`status_type` 和 `updated_at`，便于后台直接展示状态和最近维护时间。完整字段备注见 [schema.sql](/Users/abc123/workspace/home-service-payment-system/systems/ops-config-system/database/schema.sql)。

## 变更台账字段

`t_ops_config_change` 用于记录配置启停变更的申请、审批、灰度窗口和发布事实。

| 字段 | 含义 |
| --- | --- |
| `request_no` | 变更申请号，唯一业务键 |
| `config_type` / `config_code` | 目标配置类型与编码 |
| `target_status` | 发布后的目标状态 |
| `reason` | 变更原因 |
| `gray_scope` | 灰度范围 |
| `gray_start_at` / `gray_end_at` | 灰度发布时间窗 |
| `applicant` / `approver` | 申请人与审批人 |
| `approval_comment` | 审批意见 |
| `status` | 待审批、已审批、已拒绝、已发布或已过期 |
| `created_at` / `approved_at` / `published_at` | 关键时间留痕 |

申请号唯一索引保证重复查询可定位同一变更，状态和配置维度索引服务待审批列表及配置历史回查。
