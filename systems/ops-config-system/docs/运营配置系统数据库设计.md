# 运营配置系统数据库设计

## 数据库

独立数据库：`housekeeping_ops_config`。

## 表设计

| 表名 | 说明 |
| --- | --- |
| `t_ops_agreement_template` | 协议模板 |
| `t_ops_business_line` | 业务线 |
| `t_ops_payment_type` | 支付类型 |
| `t_ops_cashier_template` | 收银台模板 |
| `t_ops_channel_profile` | 渠道档案 |
| `t_ops_routing_rule` | 路由规则 |
| `t_ops_system_control` | 系统控制 |

所有表统一包含 `status`、`status_type` 和 `updated_at`，便于后台直接展示状态和最近维护时间。完整字段备注见 [schema.sql](/Users/abc123/workspace/home-service-payment-system/systems/ops-config-system/database/schema.sql)。
