# 运营配置系统接口文档

基础地址：`/api/ops-config`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/summary` | 查询总览指标 |
| GET | `/agreement-templates` | 查询协议模板 |
| GET | `/business-lines` | 查询业务线 |
| GET | `/payment-types` | 查询支付类型 |
| GET | `/cashier-templates` | 查询收银台模板 |
| GET | `/channel-profiles` | 查询渠道档案 |
| GET | `/routing-rules` | 查询路由规则 |
| GET | `/system-controls` | 查询系统控制 |
| GET | `/effective-snapshot` | 查询当前业务场景的有效配置快照 |
| GET | `/effective-snapshot/export` | 导出当前业务场景的有效配置快照 |
| POST | `/agreement-templates/toggle` | 启停协议模板 |
| POST | `/business-lines/toggle` | 启停业务线 |
| POST | `/payment-types/toggle` | 启停支付类型 |
| POST | `/cashier-templates/toggle` | 启停收银台模板 |
| POST | `/channel-profiles/toggle` | 启停渠道档案 |
| POST | `/routing-rules/toggle` | 启停路由规则 |
| POST | `/system-controls/toggle` | 启停系统控制 |
| POST | `/changes` | 创建配置变更申请 |
| GET | `/changes` | 查询配置变更记录 |
| POST | `/changes/approve` | 审批配置变更 |
| POST | `/changes/publish` | 在灰度窗口内发布配置变更 |

启停请求示例：

```json
{
  "configCode": "ROUTE_HOME_DEPOSIT",
  "enabled": true
}
```

响应统一为 `{code,message,data,requestId}`，`code=0` 表示成功。

## 有效配置快照接口

### 请求示例

`GET /api/ops-config/effective-snapshot?businessCode=HOME_CLEAN&payType=PAY_CONSUME&terminalType=APP`

### 适用场景

1. `payment-core` 在支付提交前补齐默认支付方式、默认渠道和系统控制项。
2. `risk-control-system` 后续读取大额复核、限额开关等统一控制项。
3. 前端收银台在没有显式下发默认值时，可通过支付核心侧的联动结果获得一致展示。

### 响应示例

```json
{
  "code": "0",
  "message": "success",
  "data": {
    "businessCode": "HOME_CLEAN",
    "payType": "PAY_CONSUME",
    "terminalType": "APP",
    "defaultPayMethod": "微信支付",
    "primaryChannelProfileCode": "CHANNEL_WX_H5",
    "backupChannelProfileCode": "CHANNEL_ALI_APP",
    "routeMatchPolicy": "按业务线+支付类型命中",
    "enabledSystemControls": [
      {
        "controlCode": "CONTROL_PAYMENT_TIMEOUT",
        "controlName": "支付超时关闭",
        "controlScope": "payment-core",
        "controlValue": "30m",
        "riskLevel": "LOW",
        "status": "ENABLED",
        "statusType": "success",
        "updatedAt": "2026-08-04 10:00:00"
      },
      {
        "controlCode": "CONTROL_BIG_AMOUNT_REVIEW",
        "controlName": "大额人工复核",
        "controlScope": "risk-control-system",
        "controlValue": "5000",
        "riskLevel": "HIGH",
        "status": "ENABLED",
        "statusType": "success",
        "updatedAt": "2026-08-04 10:00:00"
      }
    ]
  },
  "requestId": "REQ-OPS-20260804-001"
}
```

### 字段说明

| 字段 | 含义 |
| --- | --- |
| `businessCode` | 业务线编码，例如家政保洁、保证金、充值等 |
| `payType` | 支付类型编码，例如消费支付、充值支付、保证金支付 |
| `terminalType` | 当前终端类型，例如 `APP`、`PC`、`H5` |
| `defaultPayMethod` | 收银台默认支付方式 |
| `primaryChannelProfileCode` | 优先渠道档案编码 |
| `backupChannelProfileCode` | 备选渠道档案编码 |
| `routeMatchPolicy` | 当前命中的路由策略说明 |
| `enabledSystemControls` | 当前场景下的统一控制项集合 |

### 快照门禁

1. `businessCode` 对应业务线必须启用。
2. `payType` 对应支付类型必须启用。
3. `terminalType` 对应收银台模板必须启用。
4. `businessCode + payType` 对应路由规则必须启用。
5. 路由规则依赖的主渠道、备选渠道档案必须启用。
6. 任一关键项缺失时，接口直接返回业务异常，不下发半成品快照。

## 配置版本与灰度发布接口

### 创建变更申请

`POST /api/ops-config/changes`

```json
{
  "configType": "ROUTING_RULE",
  "configCode": "ROUTE_HOME_DEPOSIT",
  "enabled": true,
  "reason": "恢复家政保证金支付路由",
  "grayScope": "HOME_DEPOSIT",
  "grayStartAt": "2026-08-09 10:00:00",
  "grayEndAt": "2026-08-09 12:00:00",
  "applicant": "ops-owner"
}
```

创建成功后状态为 `PENDING_APPROVAL`，系统生成唯一 `requestNo`。`configType` 支持：
`AGREEMENT_TEMPLATE`、`BUSINESS_LINE`、`PAYMENT_TYPE`、`CASHIER_TEMPLATE`、
`CHANNEL_PROFILE`、`ROUTING_RULE`、`SYSTEM_CONTROL`。

### 审批变更

`POST /api/ops-config/changes/approve`

```json
{
  "requestNo": "OPSCHG-20260809-001",
  "approved": true,
  "approver": "finance-owner",
  "approvalComment": "确认影响范围后通过"
}
```

只有 `PENDING_APPROVAL` 可以审批；通过后为 `APPROVED`，拒绝后为 `REJECTED`。

### 发布变更

`POST /api/ops-config/changes/publish`

```json
{
  "requestNo": "OPSCHG-20260809-001",
  "operator": "ops-owner"
}
```

只有 `APPROVED` 变更可以发布。开始时间未到达时拒绝发布，结束时间已过期时记录为
`EXPIRED`；发布成功后才更新目标配置表状态，并将变更记录置为 `PUBLISHED`。

### 变更状态

| 状态 | 含义 |
| --- | --- |
| `PENDING_APPROVAL` | 已提交，等待审批 |
| `APPROVED` | 审批通过，等待灰度窗口发布 |
| `REJECTED` | 审批拒绝 |
| `PUBLISHED` | 已更新目标配置并完成发布留痕 |
| `EXPIRED` | 超过灰度结束时间，未再允许发布 |
