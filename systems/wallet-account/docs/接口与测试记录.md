# wallet-account 接口与测试记录

更新时间：2026-08-02

## 当前接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/wallet/accounts` | 账户分页查询，支持 `keyword`、`ownerType`、`accountStatus` |
| `GET` | `/api/wallet/accounts/{walletAccountNo}` | 账户详情与最近流水 |
| `GET` | `/api/wallet/accounts/{walletAccountNo}/balance` | 五类余额查询 |
| `GET` | `/api/wallet/accounts/balances` | 批量余额查询，参数 `walletAccountNos=a,b` |
| `POST` | `/api/wallet/accounts/balances/query` | 批量余额查询，请求体传账户号列表 |
| `GET` | `/api/wallet/flows` | 流水分页查询，支持账户号、来源系统、来源业务单号 |
| `POST` | `/api/wallet/flows/export` | 异步导出钱包流水，返回导出任务编号 |
| `POST` | `/api/wallet/accounts` | 幂等开户 |
| `POST` | `/api/wallet/accounts/{walletAccountNo}/status-change` | `INIT -> ACTIVE`、`ACTIVE <-> FROZEN`、零余额 `ACTIVE -> CLOSED` |

## 2026-08-02 真实 HTTP 回归样本

1. 列表查询：`GET /api/wallet/accounts?pageNo=1&pageSize=10` 返回 4 条记录，包含 `WA-USER-001`、`WA-WORKER-001` 与两笔并发演练开户样本
2. 账户详情：`GET /api/wallet/accounts/WA-USER-001` 返回账户、余额、最近流水，最近流水包含 `WF-0001` 开户与 `WF-0002` 充值在途入账
3. 余额查询：`GET /api/wallet/accounts/WA-USER-001/balance` 返回 `total=268.00`、`available=240.00`、`frozen=20.00`
4. 流水分页：`GET /api/wallet/flows?walletAccountNo=WA-USER-001&pageNo=1&pageSize=20` 返回 2 条流水，分页结构为 `total + records`
5. 幂等开户首次写入：`POST /api/wallet/accounts` 使用 `requestNo=REQ-WALLET-20260802-132900` 新建账户 `WA-BE356919332C`
6. 幂等开户重复命中：同 `requestNo` 再次调用返回同一账户 `WA-BE356919332C`，未重复开户
7. 状态流转成功：`POST /api/wallet/accounts/WA-WORKER-001/status-change` 使用 `operatorRole=FUNDS` 完成 `FROZEN -> ACTIVE`，随后已恢复为 `FROZEN`
8. 导出受理成功：`POST /api/wallet/flows/export` 使用 `operatorRole=FINANCE` 返回导出任务 `WFE-9DF34A9C8F04`
9. 权限拒绝样本：未传或传错 `operatorRole` 时，状态流转返回 `WALLET_ACCOUNT_PERMISSION_DENIED`，导出返回 `WALLET_ACCOUNT_EXPORT_FORBIDDEN`
