# settlement-system frontend

## 说明

当前目录用于承载 `settlement-system` 的前端实现。

第一版目标：

1. admin-web 工作台
2. 结算批次页面
3. 结算单页面
4. 结算详情页
5. 审核页
6. 出款批次页
7. 结算事件页

## 当前验证

- 管理端 API client 对网络断开、请求超时和非 JSON 上游响应分别保留可识别错误码。
- admin-web Node 测试通过；工作台聚合列表对空响应统一归一，JSON 请求默认使用 `10000ms` 客户端超时并在请求结束后清理计时器，Vite 生产构建通过。
- 这些结果只证明本地前端契约和构建可用，不代表真实出款、银行通道或生产资金事实。
