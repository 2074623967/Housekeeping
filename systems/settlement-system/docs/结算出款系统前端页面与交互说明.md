# 结算出款系统前端页面与交互说明

## 1. 页面范围

### admin-web

1. 结算批次列表页
2. 服务者结算单列表页
3. 商家结算单列表页
4. 结算单详情页
5. 审核页
6. 出款批次页
7. 出款跟踪页

## 2. 页面职责

### 2.0 结算工作台

- 作为运营首页，集中展示待审核、失败出款、事件消费和批次推进情况
- 支持从首页直接跳转审核工作台、结算单、出款批次、结算事件页
- 首页必须展示最近批次、风险出款批次、最近结算单、最近事件四块摘要区

### 2.1 结算批次列表页

- 查看批次状态、金额、审核状态、出款状态
- 支持下钻查看批次摘要和关联结算单列表

### 2.2 结算单列表页

- 查看应结金额、扣减金额、实结金额
- 支持审核、退回、发起出款

### 2.3 结算单详情页

- 展示结算来源、费用项、扣减项和审核记录

### 2.4 出款跟踪页

- 展示批次出款进度和失败明细
- 支持查看单个出款批次下的出款记录列表
- 支持对待出款草稿执行出款，并录入执行人、执行备注和模拟执行结果
- 支持针对失败批次执行人工补发重试

## 3. 交互要求

1. 所有金额字段必须高亮展示
2. 审核和出款必须二次确认
3. 失败记录必须支持重试
4. 详情必须可下钻到明细项
5. 结算批次页必须支持同页查看批次摘要和关联结算单
6. 创建出款草稿与执行出款必须拆分为两个明确动作，禁止创建草稿时直接改变结算单出款状态

## 4. 2026-07-25 本轮补充

### 4.1 出款批次页

- 在批次列表新增 `查看出款记录` 操作
- 当批次存在失败记录时展示 `失败重试` 操作
- 重试前要求录入操作人和重试原因，并进行二次确认

### 4.2 出款记录跟踪区

- 在同页下方新增出款记录跟踪区，减少运营跳转成本
- 展示字段包含：出款单号、批次号、结算单号、对象信息、金额、状态、重试次数、创建时间
- 支持按出款状态刷新当前批次记录
- 当列表为空时必须给出空态提示

### 4.3 出款执行区

- 出款批次页新增执行人、执行备注、执行结果和失败原因输入项
- 仅 `待出款`、`处理中`、`待重试` 批次展示 `执行出款`
- 执行前必须二次确认，执行成功后刷新批次和出款记录

## 5. 2026-07-28 本轮补充

### 5.1 结算单列表页

- 列表页补齐同页审核闭环：查询、查看详情、审核通过、驳回
- 审核动作前必须二次确认，并复用统一审核人、审核备注输入区
- 同页下方新增 `结算单处理明细` 区，展示对象信息、批次状态、审核状态和出款状态
- 明细区拆分为 `金额明细` / `审核日志` 双标签，减少页面跳转
- 金额字段统一高亮，其中扣减金额使用红色强调异常/扣减语义

### 5.2 结算详情页

- 详情页补齐完整摘要区：结算单号、结算对象、审核/出款状态、实结金额
- 详情页必须完整展示金额明细表和审核日志表，支持财务复核与问题定位

### 5.3 审核工作台

- 原独立审核页升级为 `审核工作台`，默认按 `待审核` 队列过滤
- 页面分为上方审核队列、下方审核详情面板两部分
- 审核人和审核备注采用统一输入区，支持快速填充通过/驳回话术
- 审核详情面板必须展示金额明细和审核日志，避免财务重复跳页核对

### 5.4 结算事件页

- 事件页升级为 `事件列表 + 关联结算单` 双区联动工作台
- 支持录入完整清分事件字段，模拟服务者/商家两类事件样例
- 事件消费成功后，应自动下钻到对应 `clearingNo` 的关联结算单列表
- 下方关联区必须展示事件载荷、结算单金额和审核状态，便于核验跨系统链路

### 5.5 结算工作台首页

- 首页升级为运营驾驶舱，分为 `核心待办`、`批次进度与风险出款`、`最近待审核与事件动态` 三块
- 核心待办卡片需直出待审核单数、驳回待修正数、失败出款批次数、事件追踪数
- 驾驶舱需支持手工刷新，保证运营查看最新数据
