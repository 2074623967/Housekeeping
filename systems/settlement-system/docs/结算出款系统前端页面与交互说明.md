# 结算出款系统前端页面与交互说明

## 1. 页面范围

### admin-web

1. 结算批次列表页
2. 服务者结算单列表页
3. 商家结算单列表页
4. 结算单详情页
5. 审核页
6. 出款批次页
7. 出款跟踪页

## 2. 页面职责

### 2.1 结算批次列表页

- 查看批次状态、金额、审核状态、出款状态

### 2.2 结算单列表页

- 查看应结金额、扣减金额、实结金额
- 支持审核、退回、发起出款

### 2.3 结算单详情页

- 展示结算来源、费用项、扣减项和审核记录

### 2.4 出款跟踪页

- 展示批次出款进度和失败明细
- 支持查看单个出款批次下的出款记录列表
- 支持针对失败批次执行人工补发重试

## 3. 交互要求

1. 所有金额字段必须高亮展示
2. 审核和出款必须二次确认
3. 失败记录必须支持重试
4. 详情必须可下钻到明细项

## 4. 2026-07-25 本轮补充

### 4.1 出款批次页

- 在批次列表新增 `查看出款记录` 操作
- 当批次存在失败记录时展示 `失败重试` 操作
- 重试前要求录入操作人和重试原因，并进行二次确认

### 4.2 出款记录跟踪区

- 在同页下方新增出款记录跟踪区，减少运营跳转成本
- 展示字段包含：出款单号、批次号、结算单号、对象信息、金额、状态、重试次数、创建时间
- 支持按出款状态刷新当前批次记录
- 当列表为空时必须给出空态提示
