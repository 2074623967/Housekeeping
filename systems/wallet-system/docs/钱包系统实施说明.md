# 钱包系统实施说明

## 1. 文档定位

本文档用于说明 `wallet-system` 的建设目标、范围和开发顺序。

## 2. 建设目标

建立一套独立的钱包与营销资金系统，承接：

1. 余额支付
2. 充值
3. 提现
4. 转账
5. 红包与营销资金
6. 钱包流水和审批留痕

## 3. 一期范围

第一批范围包括：

1. 钱包账户
2. 钱包余额
3. 钱包流水
4. 余额支付
5. 充值
6. 提现
7. 转账
8. 营销资金台账

## 4. 当前已交付

1. 钱包账户列表与详情查询
2. 钱包余额支付单创建与余额扣减
3. 余额支付流水留痕
4. 钱包充值单创建与余额加账
5. 充值流水留痕
6. 钱包提现单创建与余额扣减
7. 提现流水留痕
8. 钱包转账单创建与双边余额变更
9. 转账双边流水留痕
10. 红包池批次创建、营销资金扣减与流水留痕
11. 钱包流水独立查询页与筛选能力
12. 大额红包待风控审批、审批通过后再完成营销资金扣减
13. 营销资金台账聚合看板，统一查看余额、红包、审批和支出流水

## 5. 开发顺序

1. 钱包账户与余额
2. 余额支付
3. 充值
4. 提现
5. 转账
6. 红包与营销资金
