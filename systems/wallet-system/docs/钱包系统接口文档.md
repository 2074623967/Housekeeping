# 钱包系统接口文档

## 1. 钱包账户

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/accounts` | `GET` | 查询钱包账户列表 |
| `/api/wallet/accounts/{accountNo}` | `GET` | 查询钱包账户详情 |

## 2. 钱包交易

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/accounts/recharges` | `POST` | 创建充值单 |
| `/api/wallet/accounts/withdrawals` | `POST` | 创建提现单 |
| `/api/wallet/accounts/transfers` | `POST` | 创建转账单 |
| `/api/wallet/accounts/balance-payments` | `POST` | 发起余额支付 |

## 3. 红包管理

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/red-packets` | `GET` | 查询红包批次列表 |
| `/api/wallet/red-packets` | `POST` | 发起红包池发放 |
