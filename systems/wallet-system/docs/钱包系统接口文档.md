# 钱包系统接口文档

## 1. 钱包账户

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/accounts` | `GET` | 查询钱包账户列表 |
| `/api/wallet/accounts/{accountNo}` | `GET` | 查询钱包账户详情 |

## 2. 钱包交易

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/recharges` | `POST` | 创建充值单 |
| `/api/wallet/withdrawals` | `POST` | 创建提现单 |
| `/api/wallet/transfers` | `POST` | 创建转账单 |
| `/api/wallet/balance-payments` | `POST` | 发起余额支付 |
