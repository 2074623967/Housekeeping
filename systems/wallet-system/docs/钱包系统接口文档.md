# 钱包系统接口文档

## 1. 钱包账户

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/accounts` | `GET` | 查询钱包账户列表 |
| `/api/wallet/accounts/balance-snapshots` | `GET` | 查询钱包余额快照台，输出总余额、冻结占比和资金关注标签 |
| `/api/wallet/accounts/ledgers` | `GET` | 查询钱包流水列表，可按账户号/业务类型/方向筛选 |
| `/api/wallet/accounts/ledgers/export` | `GET` | 导出钱包流水快照，按当前筛选条件留档 |
| `/api/wallet/accounts/{accountNo}` | `GET` | 查询钱包账户详情 |

## 2. 钱包交易

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/accounts/recharges` | `POST` | 按 `bizNo` 幂等创建 `PENDING` 充值单；重复请求的账户与金额必须一致，不增加余额或写充值流水 |
| `/api/wallet/accounts/withdrawals` | `POST` | 创建提现单 |
| `/api/wallet/accounts/transfers` | `POST` | 创建转账单 |
| `/api/wallet/accounts/balance-payments` | `POST` | 发起余额支付 |

充值单目前只是待支付意向；尚无可信的支付成功回调、归属校验与到账幂等处理，不得将创建成功视作到账。现有 `SUCCESS` 演示种子仅供本地展示。

## 3. 红包管理

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/red-packets` | `GET` | 查询红包批次列表 |
| `/api/wallet/red-packets` | `POST` | 发起红包池发放 |

## 4. 风控审批

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/risk-events` | `GET` | 查询风控事件列表 |
| `/api/wallet/risk-events/approve` | `POST` | 执行风控审批通过/驳回 |

## 5. 营销资金台账

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/wallet/marketing-funds/dashboard` | `GET` | 查询营销资金账户、红包批次、审批事件与支出台账聚合看板 |
