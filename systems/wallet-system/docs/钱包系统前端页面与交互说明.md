# 钱包系统前端页面与交互说明

## 1. 页面范围

### 1.1 admin-web

1. 钱包账户列表
2. 钱包账户详情
3. 余额支付操作区
4. 钱包流水页
5. 充值单列表页
6. 提现单列表页
7. 转账单列表页
8. 红包管理页
9. 风控审批页

### 1.2 app-web / h5-web / pc-web

1. 余额支付页
2. 充值页
3. 提现页
4. 转账页

## 2. 交互要求

1. 列表页必须支持搜索、重置、分页
2. 详情页必须支持侧边栏或抽屉展示
3. 钱包资金动作必须保留操作日志
4. 风控动作必须有明显提示
5. 红包管理页必须同时展示批次列表和发放表单
6. 钱包流水页必须支持账户号、业务类型、资金方向三类筛选
7. 风控审批页必须展示待审事件并支持通过/驳回处理
