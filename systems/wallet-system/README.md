# wallet-system

## 模块定位

`wallet-system` 是家政支付平台的钱包与营销资金系统，对应第四阶段建设模块。

职责包括：

- 钱包账户
- 余额支付
- 充值
- 提现
- 转账
- 红包与营销资金
- 钱包流水
- 钱包风控与审批
