# 账户账务系统前端页面与交互说明

## 1. 页面范围

### 1.1 admin-web

1. 账户主体列表
2. 账户列表
3. 余额详情页
4. 账户流水页
5. 冻结单列表页
6. 调账单列表页
7. 账户事件页

## 2. 页面职责

### 2.1 账户主体列表

- 查看主体类型、主体名称、状态
- 支持开立账户入口
- 支持主体指标卡、列表查询、右侧详情与建档建议
- 支持从主体维度观察关联账户数量与状态分布

### 2.2 账户列表

- 查看账户号、主体、账户类型、余额状态
- 支持冻结、解冻、调账、详情查看
- 支持右侧快速预览面板，联动展示余额快照与最近流水

### 2.3 余额详情页

- 展示可用余额、冻结余额、在途余额
- 展示最近变动流水

### 2.4 账户流水页

- 按账户号、业务单号、日期筛选
- 展示借贷方向、前后余额、业务类型
- 支持流水指标卡、列表查询、右侧详情与账务核对建议
- 支持按账户号从其他页面跳转后自动带入查询条件

### 2.5 冻结单列表页

- 查看冻结状态、冻结原因、解冻状态
- 支持冻结单指标卡、列表查询、右侧详情和处置建议
- 支持创建冻结单、执行解冻、核对冻结金额与业务单关联关系

### 2.6 调账单列表页

- 查看调账原因、审批状态和生效状态
- 支持调账单指标卡、列表查询、右侧详情和审批建议
- 支持创建调账单、执行审批、核对调账方向与金额依据

### 2.7 账户事件页

- 支持按事件类型、业务单号、支付单号筛选事件
- 支持手工消费支付成功、清分结果生成等账务事件
- 支持查看事件状态、链路判断、原始载荷与补偿排查信息

### 2.8 账务工作台

- 展示账户主体、账户数量、冻结调账规模、事件总量等核心指标
- 展示待处理冻结单、待审批调账单、失败事件、最近流水等运营待办
- 展示最近账户、最近流水、最近冻结单、最近调账单、最近事件等运行快照

## 3. 交互要求

1. 列表页必须支持搜索、重置、分页
2. 详情页必须支持抽屉或侧边栏展示
3. 账户列表默认自动预览首条账户，点击“快速查看”切换侧栏内容
4. 冻结、解冻、调账必须二次确认
5. 所有操作必须带操作日志留痕
6. 工作台必须提供运营待办入口，支持从首页跳转到冻结、调账、事件、流水页面
7. 事件页必须支持“列表 + 侧边链路详情”联动，方便排查消费失败与补偿场景
8. 冻结单与调账单页面必须支持“列表 + 右侧详情”联动，方便运营和财务快速处置

## 4. 设计原则

1. 页面风格与 `payment-core` 保持一致
2. 财务数据必须前置关键数字和状态标签
3. 表格必须支持高密度信息展示
4. 风险操作必须明显标识
5. 事件与账务流水页面应突出链路排查和异常补偿视角
