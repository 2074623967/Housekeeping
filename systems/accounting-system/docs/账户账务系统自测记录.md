### 本轮修正

1. `AccountingDataMapper` 新增按 `accountNo + bizType + bizNo` 查询账务流水、按 `eventType + bizNo` 查询事件台账的能力。
2. `AccountingEventServiceImpl` 在消费 `PAYMENT_SUCCESS` 和 `CLEARING_GENERATED` 事件前，先检查既有流水是否已存在，避免重复入账；事件台账也改为重复消费时复用既有事件记录。
3. 新增重复消费单测，确认同一支付成功事件重复进入后，余额不会再次增加，事件台账也不会重复写入。

### 当前判断

1. `payment-core` 或 `clearing-system` 的补偿重放再次命中 `accounting-system` 时，不会再把同一业务单号重复记账。
2. 当前仍未覆盖真实总账、凭证、会计期间关闭、差异调账审批和 MQ 级消费确认，因此仍不触发 `test -> master` 或 `release/*`。
