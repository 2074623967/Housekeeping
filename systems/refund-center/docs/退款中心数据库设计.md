# 退款中心数据库设计

数据库：`housekeeping_refund`。

| 表 | 用途 |
| --- | --- |
| `t_refund_payment_source` | 支付成功事实投影，作为退款金额校验依据 |
| `t_refund_order` | 退款主单和状态机 |
| `t_refund_operation_log` | 退款动作审计 |
| `t_refund_outbox_event` | 退款成功事件出站，包含派发状态、重试次数、最近错误信息 |

金额统一使用 `DECIMAL(18,2)`，退款单号、幂等键、日志号均设置唯一约束，状态和支付单号建立索引。
