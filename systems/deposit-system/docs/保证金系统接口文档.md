# 保证金系统接口文档

基础地址：`/api/deposits`。响应统一为 `{code,message,data,requestId}`，`code=0` 表示成功。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/overview` | 查询保证金概览工作台 |
| GET | `/accounts` | 查询账户列表 |
| GET | `/accounts/{accountNo}` | 查询账户详情工作台 |
| POST | `/accounts` | 开立保证金账户 |
| POST | `/accounts/{accountNo}/collect` | 收取保证金 |
| POST | `/accounts/{accountNo}/freeze` | 冻结保证金 |
| POST | `/accounts/{accountNo}/unfreeze` | 解冻保证金 |
| POST | `/accounts/{accountNo}/deduct` | 扣罚保证金 |
| POST | `/accounts/{accountNo}/refund` | 退还保证金 |
| POST | `/offset-debt` | 保证金抵扣欠款 |
| GET | `/accounts/{accountNo}/flows` | 查询账户流水 |

## 工作台概览响应

```json
{
  "accountCount": 12,
  "ownerCount": 12,
  "totalBalance": 6800.00,
  "totalFrozenAmount": 1100.00,
  "totalAvailableAmount": 5700.00,
  "fullyPaidAccountCount": 8
}
```

## 账户列表查询参数

| 参数 | 说明 |
| --- | --- |
| `ownerType` | 主体类型，支持 `WORKER / MERCHANT / PLATFORM` |
| `status` | 账户状态，V1 默认 `OPEN` |
| `keyword` | 模糊查询账户号或主体编号 |

## 开户请求

```json
{"ownerId":"WORKER-1001","ownerType":"WORKER","requiredAmount":500}
```

## 资金动作请求

```json
{"amount":100,"referenceNo":"PENALTY-1001","remark":"服务纠纷扣罚"}
```

## 抵扣欠款请求

```json
{"accountNo":"DEP202608040001","debtNo":"DEBT-1001","debtAmount":100,"remark":"欠款抵扣"}
```

## 流水查询参数

| 参数 | 说明 |
| --- | --- |
| `flowType` | 按流水类型筛选 |
| `referenceNo` | 按业务关联号模糊筛选 |

金额必须大于 0；账户余额、冻结额和流水变化由服务端计算，客户端不能传入变更后余额。

补充约束：

1. 同一 `ownerId + ownerType` 重复开户会直接返回业务错误。
2. 当资金动作携带 `referenceNo` 时，同一账户下相同 `flowType + referenceNo` 只允许成功一次，重复提交会返回“该业务关联号已处理，请勿重复提交”。
3. 账户详情工作台会返回流水笔数、最近流水时间、是否已缴达标和待补缴金额，用于前端运营台直接展示。
