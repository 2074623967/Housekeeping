# 保证金系统数据库设计

## 数据库

独立数据库：`housekeeping_deposit`。

## t_deposit_account

账户表保存当前余额快照。`account_no` 唯一；`owner_id + owner_type` 唯一，保证一个资金主体只有一个 V1 保证金账户。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `account_no` | varchar(64) | 账户号 |
| `owner_id` | varchar(64) | 主体编号 |
| `owner_type` | varchar(32) | 主体类型 |
| `required_amount` | decimal(18,2) | 应缴金额 |
| `balance` | decimal(18,2) | 总余额 |
| `frozen_amount` | decimal(18,2) | 冻结金额 |
| `status` | varchar(32) | 账户状态 |

## t_deposit_flow

流水表只追加不更新，记录余额和冻结额的前后快照。生产环境按 `account_no + created_at` 查询并按月归档。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `flow_no` | varchar(64) | 流水号 |
| `flow_type` | varchar(32) | 动作类型 |
| `amount` | decimal(18,2) | 发生金额 |
| `before_balance/after_balance` | decimal(18,2) | 余额前后值 |
| `before_frozen_amount/after_frozen_amount` | decimal(18,2) | 冻结额前后值 |
| `reference_no` | varchar(128) | 外部业务关联号 |

完整字段备注和索引以 `database/schema.sql` 为准。
