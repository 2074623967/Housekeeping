# 保证金系统

保证金系统负责家政服务者、商家和平台主体的保证金生命周期与资金流水。

## V1 范围

- 保证金账户开户
- 保证金收取
- 冻结、解冻
- 扣罚
- 退还
- 抵扣欠款
- 余额和流水查询
- 独立数据库 `housekeeping_deposit`

所有资金动作均写入保证金流水，状态更新采用条件更新，避免重复操作和余额透支。

## V2 方向

- 多个保证金规则归集到一个总保证金账户
- 旧品类账户余额结转到新总账户
- 保证金规则、品类、业务线与总账户建立多对一绑定
- 账户展示升级为总余额、冻结金额、可用余额、规则明细
- 当前已补齐只读预览：总账户汇总、规则绑定预览、旧账户结转预览

## 迭代原则

- V1 先保持单主体单账户的稳定交付，优先保证开户、收取、冻结、解冻、扣罚、退还和抵扣欠款闭环可用。
- V2 专门解决当前简化模型暴露出来的痛点，例如多规则归集、历史账户迁移、展示口径统一和账务追溯增强。
- 当前 V2 先落只读预览和迁移设计验证，正式写库迁移与规则绑定动作后续再进入可执行阶段。
- 若后续再出现新的业务线、角色或口径冲突，继续按版本推进，不在 V1 里无限叠加复杂度。
