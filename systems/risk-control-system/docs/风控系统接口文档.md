# 风控系统接口文档

基础地址：`/api/risk-control`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/summary` | 查询风控总览 |
| GET | `/policies` | 查询风险策略 |
| GET | `/limit-rules` | 查询限额规则 |
| GET | `/blocklists` | 查询黑名单 |
| GET | `/intercept-events` | 查询风险拦截事件 |
| GET | `/review-orders` | 查询人工复核单 |
| GET | `/monitor-rules` | 查询监控规则 |
| POST | `/policies/toggle` | 启停风险策略 |
| POST | `/limit-rules/toggle` | 启停限额规则 |
| POST | `/blocklists/toggle` | 启停黑名单 |
| POST | `/monitor-rules/toggle` | 启停监控规则 |
| POST | `/review-orders/action` | 处理人工复核单 |

启停请求示例：

```json
{
  "configCode": "POLICY_DEVICE_RISK",
  "enabled": true
}
```

人工复核示例：

```json
{
  "reviewNo": "REVIEW-1001",
  "action": "APPROVE",
  "remark": "风控审核通过"
}
```
