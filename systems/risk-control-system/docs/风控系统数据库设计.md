# 风控系统数据库设计

## 数据库

独立数据库：`housekeeping_risk_control`。

## 表设计

| 表名 | 说明 |
| --- | --- |
| `t_risk_policy` | 风险策略 |
| `t_risk_limit_rule` | 限额规则 |
| `t_risk_blocklist` | 黑名单 |
| `t_risk_intercept_event` | 风险拦截事件 |
| `t_risk_review_order` | 人工复核单 |
| `t_risk_monitor_rule` | 监控规则 |

所有表统一包含状态字段，复核单额外包含审核人；完整字段备注见 [schema.sql](/Users/abc123/workspace/home-service-payment-system/systems/risk-control-system/database/schema.sql)。

## 风控拒绝追踪边界

1. 人工复核拒绝继续由 `t_risk_review_order.review_no` 关联审核事实，不额外创建虚构风险事件。
2. 策略直接拒绝复用 `t_risk_intercept_event`，以 `decision_result=已拒绝` 保存事件，并按支付单号、命中策略和处置结果查询最新事件以实现重复评估复用。
3. 本轮未新增表、字段、索引或迁移；H2 测试不证明生产 MySQL 已执行或历史数据已完成追踪键补齐。
