## 2026-09-23 对账分页 API 空响应边界补强

管理端 `getBatches` 和 `getDifferences` 统一归一分页响应：当服务端数据为空或 `items` 不是数组时，前端按空数组、零总数和当前请求分页参数继续渲染，避免空响应导致页面访问 `null.items` 或保留上一页数据。

验证结果：reconciliation 管理端 API 测试 `7/7` 通过，Vite 生产构建通过；本轮不改变对账批次、差异处置或真实渠道账单事实。
