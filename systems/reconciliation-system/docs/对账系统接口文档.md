# 对账系统接口文档

基础地址：`http://127.0.0.1:18150`

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/api/reconciliation/overview` | GET | 工作台摘要 |
| `/api/reconciliation/batches` | GET | 批次列表 |
| `/api/reconciliation/batches/{batchNo}` | GET | 批次详情 |
| `/api/reconciliation/batches/{batchNo}/export` | GET | 导出批次详情快照 |
| `/api/reconciliation/batches` | POST | 创建批次 |
| `/api/reconciliation/batches/{batchNo}/channel-records` | POST | 写入渠道账单记录 |
| `/api/reconciliation/batches/{batchNo}/internal-records` | POST | 写入平台支付事实 |
| `/api/reconciliation/batches/{batchNo}/run` | POST | 执行自动对账 |
| `/api/reconciliation/differences` | GET | 查询差异 |
| `/api/reconciliation/differences/{differenceNo}/resolve` | POST | 人工结案 |
| `/api/reconciliation/cross-system/facts` | POST | 上报跨系统事实快照 |
| `/api/reconciliation/cross-system/chains/{businessChainId}` | GET | 查询统一业务链路事实并诊断 |

创建批次示例：

```json
{
  "businessDate": "2026-08-04",
  "channelCode": "WECHAT",
  "billSource": "CHANNEL_FILE"
}
```

批次详情返回内容：

1. 批次基础信息
2. 渠道账单记录列表
3. 平台支付事实列表
4. 差异明细列表
5. 未结案 / 已结案差异数量

跨系统事实快照上报示例：

```json
{
  "businessChainId": "CHAIN-PAY202607200001",
  "systemCode": "payment-core",
  "factType": "PAYMENT_SUCCESS",
  "factNo": "PAY202607200001",
  "businessNo": "ORD202607200001",
  "factStatus": "SUCCESS",
  "amount": 168.00,
  "snapshotVersion": 12,
  "occurredAt": "2026-08-09T10:00:00",
  "payload": "{\"paymentOrderId\":\"PAY202607200001\"}"
}
```

链路诊断规则：

1. `businessChainId + systemCode + factType + factNo` 为幂等键，重复上报不增加事实数量。
2. 任一事实状态包含 `FAILED`、`ERROR`、`ABNORMAL` 或“失败/异常”时，禁止直接进入财务收口。
3. `payload` 仅保存脱敏摘要，不保存银行卡号、证件号等敏感原文。

批次详情快照导出内容：

1. 批次汇总行
2. 渠道账单记录明细
3. 平台支付事实明细
4. 差异明细
