# 对账系统数据库设计

数据库：`housekeeping_reconciliation`。

| 表 | 作用 |
| --- | --- |
| `t_reconciliation_batch` | 批次、来源、渠道和匹配汇总 |
| `t_reconciliation_channel_record` | 渠道账单原子记录 |
| `t_reconciliation_internal_record` | 平台支付事实快照 |
| `t_reconciliation_difference` | 差异状态和人工处置 |

金额统一使用 `DECIMAL(18,2)`；批次号、渠道流水和支付单号均设置组合唯一约束或索引，保障重复导入可识别。
