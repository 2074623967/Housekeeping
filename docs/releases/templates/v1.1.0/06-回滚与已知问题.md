## 1. 回滚触发条件

- 核心支付成功率、回调收口率或资金事实出现门禁阈值异常。
- 数据库迁移、消息消费或外部通道出现不可控错误。
- 发现重复扣款、资金错账、敏感数据泄露等 P0 风险。

## 2. 回滚步骤

1. 停止流量或关闭受影响能力。
2. 保留日志、事件、数据库快照和操作审计。
3. 回滚应用版本和前端资源。
4. 按数据库变更说明执行反向处理或数据修复。
5. 重放必要事件并复核支付、清分、结算、账务事实。
