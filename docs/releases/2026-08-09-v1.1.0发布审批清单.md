## 4. 角色审批项

### 4.1 产品负责人

1. 确认本版范围仅覆盖支付主链路，不混入其他待建设子系统
2. 确认冻结候选页面与业务流程满足当前版本目标
3. 确认剩余项进入后续迭代，不阻断本版 master 观察

### 4.2 财务产品/资金负责人

1. 确认支付、清分、结算、账务主链路证据可追溯
2. 确认补偿闭环材料足够说明资金链路可控
3. 确认发布后核验重点覆盖资金事实一致性

### 4.3 后端架构负责人

1. 确认 `master` 当前未发现新的阻断级问题
2. 确认回滚边界清晰，不涉及 schema 级不可逆变更
3. 确认主链路相关脚本、证据包和运行口径已统一

### 4.4 前端负责人

1. 确认四端与后台页面冻结截图已归档
2. 确认主链路相关前端运行口径已统一
3. 确认若正式发版前还需补 UI 细节，已进入后续迭代池

### 4.5 测试负责人

1. 确认人工回归归档已可审计
2. 确认发布后现场核验项足够覆盖主链路
3. 确认 `master -> release/*` 仍需等待观察结论，不应提前切版
